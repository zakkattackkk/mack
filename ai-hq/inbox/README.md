# Inbox

Drop files here from your **phone** (Grok audits, notes, PDFs, pasted markdown) so every machine can see them after a `git pull`.

## How (phone)

1. GitHub app or browser → this folder → **Add file** → Upload (or Create new file and paste).
2. Name: `YYYY-MM-DD-short-name.md` (or keep original filename).
3. Commit.
4. Tell Mac mini Claude Code: `Pull latest. Read ai-hq/inbox/<filename>. …`

## After processing

Move the file to `../audits/` (or delete if it was only a scratch note). Keep inbox thin.
